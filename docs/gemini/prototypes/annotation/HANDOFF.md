# Annotation/composition prototype handoff

Status: Planned

## Target

Build an isolated synthetic annotation/composition proof that consumes shared metadata/layout contracts. Prefer Pillow/Fiji overlay capabilities and narrow APIs over controller-specific UI code.

## Initial scope

- strain labels;
- vertical labels;
- plate/condition labels;
- date/session labels;
- independent text/grid rotation options where useful;
- one 8x12 single-band layout and one 8x10 two-band layout;
- synthetic inputs only.

The prototype may expose a focused mini-app or callable renderer, but must not refactor the current main controller.
